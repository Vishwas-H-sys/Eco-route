# 🌱 EcoRoute — Smart Low-Carbon Navigation

EcoRoute is a web-based application that helps users choose routes based on carbon emissions instead of just distance or time. The goal is to promote environmentally friendly travel by prioritizing routes that produce less CO₂ emissions.

---

## Features

-  Eco-Friendly Route Selection  
  Suggests routes that minimize carbon emissions.

- Eco Score System  
  Provides an eco-score for each route based on environmental impact.

-  Fuel Consumption Insights  
  Estimates the amount of fuel saved by choosing greener routes.

-  CO₂ Emission Tracking  
  Displays the estimated carbon emissions for a given route.

-  Google Maps Integration  
  Uses Google Maps API to fetch routes and redirects users for navigation.

---

##  How It Works

1. The user inputs a source and destination.
2. The system fetches multiple route options using Google Maps API.
3. Each route is analyzed based on:
   - Distance  
   - Estimated fuel usage  
   - CO₂ emissions  
4. The route with the lowest carbon footprint is recommended.
5. Users are redirected to Google Maps for real-time navigation.

---

##  Tech Stack

- HTML, CSS, JavaScript  
- Google Maps API  

---

##  Limitations

-  Currently requires an internet connection (no offline support)
-  Depends on Google Maps API for route data
-  Estimations are approximate and may vary based on real-world conditions

---

##  Future Improvements

-  Offline route caching  
-  AI-based emission prediction  
-  Vehicle-type customization (bike, car, EV, etc.)  
-  Mobile app version  

---

##  Why EcoRoute?

Transportation is one of the largest contributors to carbon emissions. EcoRoute helps users make smarter decisions by showing that even small changes in route selection can lead to significant environmental impact.
